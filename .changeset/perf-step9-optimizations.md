Step 9 evidence-based performance pass. Terminal output floods (~10 MB) no longer stall the UI thread: the per-pane pending buffer is a bounded chunk FIFO (`TerminalOutputBuffer`) instead of repeated megabyte-string copies (~4.8 s to ~2.5 ms on the 20000-chunk flood benchmark). Token-budget truncation jumps to a proportional estimate plus bounded correction instead of a full binary search (~22 ms to ~8 ms on a 260 KB prompt, identical 5200-char golden boundary). Task classification reuses precompiled keyword regexes (~35 us to ~13 us per call, golden categories unchanged). Retrieval skips the per-query sha256 re-hash when size/mtime/ctime already match the index and caps per-file ranked symbols at 500 / 1000 globally, removing a quadratic cliff on symbol-dense files (1347 ms to 173 ms on a 10-file, 60000-symbol stress repo; normal queries byte-identical). The Rust backend caches the git-binary PATH probe process-wide. Indexing, git status, MCP plumbing, startup, and shutdown measured fast enough or FS-bound and were left alone. Benchmark harness under `scripts/bench/` (`npm run bench:perf`), regression tests in `src/__tests__/perf_step9_regression.test.ts`, full report in `docs/PERF_STEP9.md`.
